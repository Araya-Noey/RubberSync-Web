# 🌳 RubberSync v2 — Discord Bot (ปุ่ม + ฟอร์ม)

บอทจัดการวันเก็บยาง / วันขายยาง / ราคายางหรือราคาประมูล พร้อมเตือนอัตโนมัติและประวัติย้อนหลัง ภาษาไทย เวลาไทย

## ความสามารถ
- `/panel` ส่งแผงปุ่มแบบถาวรในห้อง Discord (ผู้ดูแลเซิร์ฟเวอร์)
- **เพิ่มรอบ** เปิดแบบฟอร์มชื่อ วันเก็บ วันขาย ราคา และประเภทราคา
- **แก้วัน/ชื่อ**, **บันทึกราคา**, **ปิดรอบ**: เลือกรอบจากเมนูดรอปดาวน์ แล้วกรอกฟอร์ม
- **ดูตาราง / ประวัติ** ผ่านปุ่ม และคำสั่ง `/schedule`, `/history`
- `/setup` เลือกห้องแจ้งเตือนและชั่วโมงล่วงหน้า 1–168 ชั่วโมง
- แจ้งเตือนก่อนวันเก็บและก่อนวันขาย; ประกาศเมื่อกำหนดการหรือราคาเปลี่ยน
- บันทึกแยกแต่ละเซิร์ฟเวอร์ใน `data/db.json`; ประวัติรอบและประวัติแก้ไขไม่หายเมื่อปิดรอบ

## การติดตั้ง (Windows / macOS / Linux)
1. ติดตั้ง Node.js **20.11+** (แนะนำ Node.js 22 LTS หรือใหม่กว่า) และตรวจสอบ `node -v`
2. เข้า https://discord.com/developers/applications → New Application → ตั้งชื่อ RubberSync
3. Bot → Reset Token และเก็บ Token เป็นความลับ
4. General Information → Copy **Application ID**
5. Discord → Settings → Advanced → เปิด Developer Mode → คลิกขวาชื่อเซิร์ฟเวอร์ → Copy Server ID
6. ไปหน้า Installation ของแอป Discord แล้วติดตั้งในเซิร์ฟเวอร์ โดยใช้ scopes **bot**, **applications.commands**; สิทธิ์ขั้นต่ำ **View Channels, Send Messages, Embed Links, Use Application Commands** ในห้องที่ใช้
7. เปลี่ยน `.env.example` เป็น `.env` ใส่ `DISCORD_TOKEN`, `CLIENT_ID`, `GUILD_ID`
8. เปิด Terminal ในโฟลเดอร์นี้ รัน:

```bash
npm install
npm test
npm start
```

9. Discord: `/setup channel:#ห้องแจ้งเตือน hours:24` จากนั้น `/panel` เพื่อเปิดแผงปุ่มและสร้างรอบ

## รูปแบบกรอก
- วันเวลา: `2026-10-20 09:00` (ปี **ค.ศ.**, ใช้เวลาไทย UTC+7)
- ราคา: `65.50` บาท/กก.; เว้นว่างได้เมื่อสร้างรอบ
- ประเภทราคา: `normal` = ราคายาง, `auction` = ราคาประมูล
- ฟอร์มแก้ไข: เว้นว่างในช่องที่ไม่ต้องการเปลี่ยน
- ปิดรอบ: พิมพ์ `CLOSE` เพื่อยืนยัน (ไม่ลบข้อมูลย้อนหลัง)

## ความปลอดภัยและข้อจำกัด
- ผู้ดูแลที่มี **Manage Server** เท่านั้นที่เพิ่ม/แก้/ปิดรอบและตั้งค่าแผง; สมาชิกทั่วไปดูตาราง/ประวัติได้
- ฟอร์มตอบกลับส่วนตัว (ephemeral); แผงปุ่ม `/panel` แสดงในห้องให้สมาชิกเห็น แต่ปุ่มแก้ข้อมูลตรวจสิทธิ์อีกครั้ง
- ตั้งค่าห้องเตือนด้วย `/setup` และตรวจสอบสิทธิ์ของบอทในห้องนั้น
- เตือนทุก 60 วินาทีเมื่อยังไม่ถึงเวลานัดและอยู่ในช่วงก่อนนัด; **ไม่ย้อนหลังเมื่อบอทออฟไลน์จนเลยเวลา**
- ต้องเปิดบอทตลอด 24 ชั่วโมงหากต้องการแจ้งเตือนแน่นอน และใช้ที่เก็บไฟล์ถาวร
- เก็บข้อมูลใน `data/db.json`, สำรองไฟล์นี้สม่ำเสมอ การแก้ไขใช้การเขียนไฟล์ชั่วคราวแล้วเปลี่ยนชื่อ
- ถ้าเริ่มจาก RubberSync v1 ให้คัดลอก `data/db.json` เดิมมาโฟลเดอร์ `data/` ของรุ่นนี้ (รองรับรูปแบบข้อมูลเดิม)
- รายการในตารางแสดง 10 รอบ เมนูเลือกแสดงสูงสุด 25 รอบต่อครั้ง; รอบที่ปิดแล้วดูใน `/history id:<เลข>` ได้
- ห้ามแชร์ Token และห้าม commit `.env` ลง Git
